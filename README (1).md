# Student VR Starter Project

Open `index.html` in a browser or code editor.

## First tasks

1. Run the file before changing anything.
2. Change the room colours.
3. Move the switch to a new position.
4. Change the message text.
5. Add one new A-Frame primitive.
6. Test that the switch still opens the door.

## Important rule

Change one thing at a time and test after each change.

The project loads A-Frame from the official A-Frame CDN, so internet access is required when the page first loads.
