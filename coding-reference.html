1. HTML document structure

<!doctype html>
<html>
<head>
  <title>My page</title>
</head>
<body>
  Page content goes here.
</body>
</html>

2. A-Frame setup

<script src="https://aframe.io/releases/1.7.1/aframe.min.js"></script>

<a-scene>
  <!-- VR objects go here -->
</a-scene>

3. Common A-Frame primitives

PrimitiveExample
Box<a-box position="0 1 -3" color="red"></a-box>
Sphere<a-sphere position="0 1 -3" radius="1" color="blue"></a-sphere>
Cylinder<a-cylinder position="0 1 -3" radius="0.5" height="2"></a-cylinder>
Plane<a-plane rotation="-90 0 0" width="10" height="10"></a-plane>
Text<a-text value="Hello" position="0 2 -3"></a-text>

4. Position, rotation and scale

A-Frame uses x y z.

position="2 1 -4"
rotation="0 45 0"
scale="1.5 1.5 1.5"
  • X = left/right
  • Y = up/down
  • Z = forward/backward

  button.setAttribute('color', 'green');

8. If / else

if (keysCollected >= 3) {
  openDoor();
} else {
  showMessage('Find more keys.');
}

9. Functions

function showMessage(message) {
  text.setAttribute('value', message);
}

showMessage('Puzzle solved!');

10. Animation

door.setAttribute('animation', {
  property: 'position',
  to: '3 1.5 -4',
  dur: 700
});

11. Debugging checklist

  1. Check every opening tag has a closing tag.
  2. Check quotation marks.
  3. Check braces { } and parentheses ( ).
  4. Check IDs match exactly.
  5. Open the browser console and read error messages.
  6. Use console.log(variableName); to inspect values.
  7. Return to the last working version and change one thing at a time.
